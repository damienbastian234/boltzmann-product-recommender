# Simplified Boltzmann Machine for Product Recommendation

## Problem Statement

A recommendation application stores binary user preferences
for different products. This project develops a simplified
Boltzmann Machine to demonstrate how hidden units learn
latent preference patterns.

## Objectives

- Prepare a binary user-product preference dataset.
- Represent preferences using visible units.
- Learn latent patterns using hidden units.
- Estimate product preference probabilities.
- Generate product recommendations.
- Evaluate the trained model.
